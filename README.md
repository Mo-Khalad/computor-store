<h1>Computor-Store</h1>
<p>An engaging e-commerce website that provides easy access to computer products and delivers a seamless shopping experience. The website includes dedicated pages for the home page, login, account creation, product details, shopping cart, and checkout.

It offers a wide range of products, including mice, motherboards, keyboards, hard drives, RAM, headphones, graphics cards, and computer monitors.

The website uses a mock API to fetch product data and a real API for user authentication. It also includes form validation, local storage, loading indicators, and toast notifications for cart actions.

Users can add products to the cart, increase or decrease quantities, and remove individual products or all products. The website also includes modals for search and login, as well as a responsive slider.

The website is fully responsive and optimized for different screen sizes.</p>

<h3>Tools</h3>
<p>Html , Css , Bootstrap and Js</p>

<h3>Features</h3>
<ul>
  <li>An attractive, elegant website that is fully responsive across all screen sizes. </li>
  <li>Authentication system with the ability to create a new account or log in with an existing one.</li>
  <li>shopping cart functionality to add products, increase/decrease quantities, and remove products</li>
  <li>Form validation using Regular Expressions (Regex).</li>
  <li>Product search functionality by product name and price, or by product name only.</li>
  <li>Data persistence using Local Storage, even after refreshing the page.</li>
</ul>
